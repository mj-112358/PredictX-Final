# Reconstruction verification

## Retained implementation

The repository contains typed observation ingestion, canonical snapshot verification, shared biochemical recipes, independent fitted models, a complete-state compatibility controller, applicability checks, endpoint-specific calibration, integrated reporting, FastAPI and Streamlit. Five deployed model files retain their original SHA-256 digests.

## Repository cleanup

The recoverable pre-reconstruction backup is stored outside the repository. Removed material comprises molecular/GEO research, Coimbra experiments, multitask/residual training branches, policy and value-of-information simulations, duplicate processing implementations, historical archives, superseded registries, patent drafts, redundant figures/reports, process files and logs. The final Word specification accompanies the implementation map.

Original tests of active behavior are retained. Tests for shared-network gradients, simulated decision policies and paired molecular observations were replaced with independent-perceptron, complete-state signature and partition-integrity tests. The preserved baseline suite passed 64 tests before reconstruction. The final suite passes **70 tests**, including concentration-unit equivalence, source-metadata mutation, feature-engine cache separation and interactive CBC assessment. One dependency deprecation warning originates from FastAPI/Starlette's HTTPX test integration.

## Scientific verification

- Public source-file hashes and partition disjointness verified for all five models.
- Training imputation, scaling and empirical bounds reconstructed and matched.
- Sigmoid calibrators refitted on the original calibration partitions and matched.
- All three original candidate families' calibrated validation comparisons reproduced.
- All five component AUROCs, confidence intervals, Brier scores, log losses and confusion counts reproduced.
- Saved test predictions matched with maximum absolute score difference ≤1.2 × 10⁻¹⁶.
- Every eligible test record matched the common inference path.
- Nested liver/cardiovascular reruns matched 22 inner-CV rows, six outer-CV rows and ten model-selection rows; both retained baseline selections reproduced.
- ROC curves, calibration plots and confusion matrices regenerated for each model and inspected.

Detailed numerical records are in `results/reproduced/evaluation` and `results/reproduced/nested_verification.json`. Original source predictions and model-selection evidence remain alongside the retained artifacts.

## Computational verification

All seven modes completed five warm-ups, eight randomized rounds and three repetitions at batch sizes 1, 8 and 32. Every execution's five scores matched the integrated reference. Single-record operation counts reproduce 190 versus 38 canonical operations and five versus four transformations.

| Integrated scalar | 12.271 | 5.315 |

Fresh-process startup, peak resident-set size, model sizes and warmed model-loading measurements were rerun. The original and regenerated environment records identify their corresponding measurements. Numerical preprocessing and predictions match; host-sensitive resource measurements differ between runs.
